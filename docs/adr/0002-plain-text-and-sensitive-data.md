# 0002. Plain text only, password-manager copies skipped

- **Status:** Partly superseded. Storage is replaced by [0003](0003-encrypted-history.md),
  "plain text only" by [0004](0004-copied-images.md).
- **Date:** 2026-10-23

## Context

A clipboard history writes to disk everything you copy, passwords included.

## Decision

- First version: plain text only. Images, files and rich text come later.
- Copies flagged `org.nspasteboard.ConcealedType`, `TransientType` or `AutoGeneratedType`, and the
  1Password type, are never captured. This is the convention password managers follow
  ([nspasteboard.org](http://nspasteboard.org)).
- History stored in `~/Library/Application Support/Pressoir/history.json`, mode 0600.
- The log (`~/Library/Logs/Pressoir.log`) never contains copied content.
- At most 50 unpinned entries. Pinned entries do not count and are never evicted.

## Consequences

- ✅ A password copied from a password manager never reaches the file.
- ⚠️ A password copied from an app that does not set the marker is kept. The user deletes it
  (<kbd>⌘⌫</kbd>) or clears the history.
